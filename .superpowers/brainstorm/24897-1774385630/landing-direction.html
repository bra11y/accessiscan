A — Editorial Dark

Inspired by the Vitalik prompt: animated grid, lime-green accents, monospace labels, marquee strip, stat counter grid. Dark by default, inverts gracefully to a pale cream/off-white in light mode. Bold typographic personality.

  • High personality, memorable
  • Space Mono + Syne fonts
  • Pill badges, section numbers (01 — Hero, 02 — Features)
  • Animated CSS grid background

Standard high-converting SaaS landing page. Indigo brand, white light mode, dark mode via system preference. Familiar and trustworthy. Rounded cards, gradient CTAs, feature grid.

  • Familiar, high-trust aesthetic
  • Inter / system font stack

C — Hybrid Editorial

Takes editorial elements (monospace labels, section numbers, pill badges, stat grids, minimal borders) but in an off-white/cream light mode. Dark mode via system preference uses a warm near-black. Green accent shifts to match each mode.

  • Distinctive but professional
  • Space Mono labels + modern display font
  • Off-white (#f9f8f5) light / warm black dark
  • No grid animation — cleaner, faster

Click a card to select. All three support system light/dark preference and pass WCAG contrast minimums in both modes.
